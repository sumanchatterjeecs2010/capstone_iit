sample_data/ — Optional demo note + image pairs
===============================================

Five fictional patient notes plus public Wikimedia images
(3 radiology, 2 pathology). Useful for a quick local or Colab demo.

Not required for grading: pass any radiology/pathology note+image to main.py, e.g.

  python main.py --text ..\sample_data\patient_01.txt --image ..\sample_data\patient_01.jpg

Credits: IMAGE_SOURCES.txt
Notes are synthetic teaching material only.
