Multimodal Medical Assistant — Execution Guide
HPPCS[04] Capstone Submission
========================================

WHAT THIS PROJECT DOES
----------------------
Combines a radiology scan or histopathology slide with a clinical note to produce:
  • Auto-detected domain (radiology or pathology)
  • Triage, impression, findings, recommendations
  • Image–note grounded findings
  • Optional terminal follow-up chat (--tui)
  • Label-free evaluation metrics (work on any input pair)

Runs on both CPU and GPU without code changes:
  • 16 GB RAM CPU laptop (default; MedGemma unloaded after vision)
  • Local NVIDIA GPU (auto-detected) or Google Colab T4
  • Compact models (MedGemma 4B + Llama 3.2 3B)

How to run (primary):
        python main.py --text <note.txt> --image <scan.jpg>

Output (always in Codebase/, next to main.py):
        conversation.json

ACCEPTED INPUT
--------------
  • Clinical note: .txt or .md
  • Image: radiology (X-ray, CT, MRI) OR histopathology (.jpg, .png, .dcm)
  • Domain is auto-detected — do not use dermatology photos or clinical snapshots


ONE-TIME SETUP
--------------
1. Install Python 3.10+.

2. Open a terminal in the Codebase folder:
        cd Codebase

3. (Recommended) Create a virtual environment:
        Windows:   python -m venv venv
                   venv\Scripts\activate
        Linux/Mac: python3 -m venv venv && source venv/bin/activate

4. Install dependencies:
        pip install -r requirements.txt

5. Install Ollama from https://ollama.com and start the Ollama app/daemon.

6. Pull models (first run may take several minutes):
        ollama pull medgemma:4b
        ollama pull llama3.2:3b
   Low RAM fallback:
        ollama pull llama3.2:1b
        python main.py --model llama3.2:1b --text <note.txt> --image <scan.jpg>

7. Verify Ollama is running:
        ollama list


CPU vs GPU
----------
Default is auto-detect (NVIDIA GPU if nvidia-smi lists one; otherwise CPU):

        python main.py --text <note.txt> --image <scan.jpg>
        python main.py --text <note.txt> --image <scan.jpg> --device auto

Force CPU:

        python main.py --text <note.txt> --image <scan.jpg> --device cpu

Force GPU (local CUDA or Colab T4):

        python main.py --text <note.txt> --image <scan.jpg> --device gpu

On CPU/GPU the vision model is unloaded after analysis so Llama can use memory.
Google Colab: open Run_on_Google_Colab.ipynb, attach T4 GPU (or CPU), follow the notebook.


Steps:
  1. Pass --text and --image
  2. Wait for analysis (several minutes on CPU; faster on GPU)
  3. Review triage, findings, and Evaluation metrics in the terminal
  4. Ask follow-up questions at the You> prompt (conversation continues)
  5. Type quit or exit when finished
  6. Open Codebase/conversation.json for the full structured output

Evaluation metrics (label-free; work on any file):
  • Cross-modal correlation
  • Robustness to data variation
  • Explanation quality
  • User satisfaction (interface and explanations, 1–5 Likert proxies)


RUN — OPTIONAL TUI (FOLLOW-UP CHAT)
-----------------------------------
Steps:
  1. Enter note and image paths if not passed on the command line
  2. Wait for analysis; review printed triage / findings / metrics
  3. Ask follow-up questions at the You> prompt
  4. Type quit or exit when finished
  5. Codebase/conversation.json is updated after each turn
